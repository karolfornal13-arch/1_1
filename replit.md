# java-example0

A minimal Java 21 console application that prints `Hello, World!`.

## Run

- Click **Run** to compile `src/main/java/Main.java` into `out/` and launch `Main`.
- Or run `javac -d out src/main/java/Main.java` followed by `java -cp out Main`.

## Requirements

- JDK 21 (`java` and `javac`)
- No frameworks or external dependencies
